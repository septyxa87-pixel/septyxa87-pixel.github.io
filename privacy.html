Privacy Policy

ACTON Studio · Effective date: 23 November 2026

ACTON Studio ("the application") is the publishing assistant used by the creator of the YouTube channel ACTON (@ACTON87) to publish and analyse the channel's own videos. It runs on the creator's computer and is used only by the channel owner. This policy explains which Google user data the application accesses, how it is used, stored, protected and deleted.

1. Google user data the application accesses

When the channel owner authorises the application with Google OAuth, it requests these permissions:

  • youtube.upload — upload videos to the owner's channel;
  • youtube.force-ssl — manage the owner's own videos: playlists, subtitles (captions), thumbnails, video settings such as publication time and content disclosures;
  • youtube.readonly — read the owner's channel and video information;
  • yt-analytics.readonly — read YouTube Analytics reports of the owner's channel (views, watch time, average view duration, subscribers gained, likes, comments, viewer countries).

The application also reads public YouTube data (titles, publication dates, view, like and comment counts of public videos and channels) through the YouTube Data API with an API key, to study which topics interest French-speaking audiences. It does not access private data of other channels or users.

The application does not request or access the owner's e-mail, contacts, Gmail, Drive or any other Google service.

2. How the data is used

  • to upload and schedule the owner's own videos and set their metadata, playlists, subtitles and thumbnails;
  • to verify after upload that the video settings were applied correctly;
  • to measure the performance of the owner's videos and improve the choice of future topics and formats;
  • to compare the owner's results with publicly available statistics of other channels.

Google user data is not used for advertising, is not sold, is not used to train generalised AI or machine-learning models, and is not used for any purpose other than the features listed above.

3. Sharing

Google user data is not shared with or transferred to any third party. Data is sent only to Google/YouTube itself when the application calls YouTube API Services on the owner's behalf.

4. Storage and protection

  • All data is stored locally on the owner's personal computer; there is no server or cloud database.
  • The OAuth refresh token is stored in a file in the owner's Windows user profile, outside the application source code and version control, readable only by the owner's Windows account. Access tokens are kept in memory only.
  • OAuth client credentials and API keys are stored outside the source code and are never written to logs.
  • Channel statistics are stored in a local database on the same computer.

5. Retention and deletion

  • Data of the owner's channel is kept while the authorisation is active and is deleted within 30 days after the authorisation is revoked.
  • Public statistics of other channels and videos are refreshed or deleted within 30 days, as required by the YouTube API Services Developer Policies.
  • The owner can revoke the application's access at any time on the Google security settings page: https://security.google.com/settings/security/permissions. After revocation the application can no longer access the account, and the stored token is deleted.
  • Deletion requests can also be sent to the contact address below.

6. YouTube API Services and Google

The application uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy. The application complies with the Google APIs Terms of Service and the YouTube API Services Developer Policies.

ACTON Studio’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

7. Cookies and children

The application has no public website functions, uses no cookies and does not track visitors of this page. It is not directed at children and does not knowingly process children's data.

8. Changes and contact

Changes to this policy are published on this page with a new effective date. Contact: github.com/septyxa87-pixel.

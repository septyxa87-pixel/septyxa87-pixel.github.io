Privacy Policy

ACTON Studio · Effective date: 23 November 2026

ACTON Studio ("the application", "we") is the publishing assistant of ACTON, a French-language documentary channel on YouTube (@ACTON87). The application runs as a desktop program on the channel creator's own computer and is used only by the channel owner. This policy describes exactly which data the application accesses through Google and YouTube, why, where it is kept, who it is shared with, how long it is kept and how it is deleted. The application uses YouTube API Services.

1. Summary

  • We access only the YouTube channel that the owner authorises (ACTON), and public YouTube statistics.
  • We use the data only to publish ACTON's videos and to measure their performance.
  • All data stays on the owner's computer. We do not sell, rent or share Google user data, and we do not use it for advertising or to train AI models.
  • Data received through the owner's authorisation is deleted no later than 30 days after the authorisation stops; public statistics are refreshed or deleted within 30 days.
  • Access can be revoked at any time at https://security.google.com/settings/security/permissions.

2. Data accessed with the owner's Google authorisation (OAuth)

The owner signs in with Google once and grants the following permissions. Each one is used only as described.

The application does not access the owner's e-mail address, Gmail, contacts, Google Drive, payment information, viewers' identities, individual comments or private messages. YouTube Analytics data is aggregated by YouTube and contains no information about individual viewers.

3. Public YouTube data (no authorisation)

With an API key, the application reads public information about French-language history videos and channels: video ID, title, channel name and ID, publication date, duration, public view, like and comment counts, and public channel information (subscriber count, number of videos, country). It is used to identify topics that interest French-speaking viewers. Public video titles may be used as search terms on Wikipedia to find the matching historical article.

4. How the data is used

  • to upload, schedule and configure ACTON's videos and confirm that every required setting was applied;
  • to compute performance indicators of ACTON's videos (for example views per day, average percentage viewed) and adjust the choice of future topics and formats;
  • to compare ACTON's results with public statistics of similar videos.

Google user data is processed automatically by the application on the owner's computer. It is not used for advertising, profiling of people, credit or lending decisions, and it is not used to develop, improve or train generalised artificial-intelligence or machine-learning models. No human other than the channel owner reads it.

5. Sharing and transfer

Google user data is not sold, rented, shared or transferred to any third party. The only recipient is Google/YouTube itself, when the application calls YouTube API Services on the owner's behalf (for example, to upload a video). The application has no servers, so data never leaves the owner's computer except in these calls to Google. Data would only be disclosed if required by law.

6. Storage and security

  • Location: a local database and local files on the owner's personal Windows computer. There is no cloud database and no remote server.
  • OAuth credentials: the refresh token is stored in a separate file in the owner's Windows user profile (outside the application's source code and version control), accessible only to the owner's Windows account. Short-lived access tokens are kept in memory only and are never written to disk or logs. The OAuth client file is stored in a folder restricted to the owner's account.
  • API responses: responses from YouTube APIs may be cached locally for up to 20 hours to avoid repeated requests; cache entries are removed within 30 days.
  • Logs: tokens, keys and passwords are never written to logs.
  • Communication with Google uses HTTPS only.

The application then immediately loses access to the account, and the stored data is deleted as described above. Immediate deletion can also be requested through the contact below.

8. Cookies and device storage

This website uses no cookies, analytics or tracking. The application stores data only on the owner's own computer, as described in section 6; it does not place cookies or store information on other people's devices.

9. Children

The application is not directed at children and does not knowingly process children's data. ACTON's videos are declared as "not made for kids".

10. Google and YouTube policies

By using ACTON Studio you agree to the YouTube Terms of Service. Google's own processing of data is described in the Google Privacy Policy. The application complies with the Google APIs Terms of Service, the YouTube API Services Terms of Service and the YouTube API Services Developer Policies.

ACTON Studio's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

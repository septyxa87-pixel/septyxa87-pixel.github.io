YouTube AI Agent

A private production assistant for the French-language documentary channel ACTON (@ACTON87).

What it does

  • Topic research. Reads public YouTube statistics (YouTube Data API) and Wikipedia page views to find historical stories — true stories, disasters, mysteries, space, civilisations — that French-speaking audiences are interested in.
  • Fact-checked scripts. Writes original French scripts and checks every date and number against several independent sources before a video is produced.
  • Video production. Narration with a synthetic voice, freely licensed archive images (authors credited), editing, French subtitles and automatic technical quality control.
  • Scheduled publishing. With the channel owner's authorisation (Google OAuth), uploads finished videos to the owner's own channel, sets title, description, playlist, subtitles, thumbnail and the publication time, then verifies the settings.
  • Channel analytics. Reads the owner's own channel statistics (YouTube Analytics API) to learn which topics and formats work best.

Who can use it

YouTube AI Agent is not a public service. It runs on the owner's personal computer and is used only by the channel owner to manage the owner's own YouTube channels. No other users can sign in, and no data from other people's Google accounts is collected.

Google and YouTube data

The application accesses Google user data only for the owner's channel and only for the purposes above. Details: Privacy Policy. YouTube AI Agent uses YouTube API Services; by using it you agree to the YouTube Terms of Service.
